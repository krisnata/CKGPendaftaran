1. Analisis Teknologi yang Digunakan
Berdasarkan struktur tag, atribut kelas CSS, dan pola interaksinya, aplikasi web CGK Kemenkes dibangun menggunakan tumpukan teknologi modern berbasis Single Page Application (SPA):

Frontend Framework: Menggunakan Vue.js (terdeteksi dari penggunaan atribut reaktif internal seperti data-v-c600345d, data-v-0dd0c770, dan struktur komponen modular).

CSS Framework / Utility: Memanfaatkan UnoCSS / Tailwind CSS (terdeteksi dari kelas penataan gaya seperti flex, grid, items-center, justify-between, rounded-lg, dan kode warna kustom).

Komponen Pilihan Tanggal (Datepicker): Menggunakan pustaka pihak ketiga berbasis Vue seperti vue-datepicker atau mx-datepicker (terdeteksi melalui kelas .mx-datepicker dan .mx-input-wrapper).

Manajemen State & Modal Interaktif: Menggunakan sistem overlay modal dinamis dengan tingkat kedalaman lapisan layar tinggi (z-index z-9000 dan kelas .modal-content) untuk menangani dropdown bertingkat.

2. Pemetaan Elemen & Modul Utama
Antarmuka pendaftaran terbagi menjadi beberapa modul elemen utama:

Modul Navigasi Samping / Atas (Dashboard Header & Sidebar):

Berisi tombol akses cepat modul klaster: Klaster 2, Klaster 3, Klaster 4.

Modul layanan khusus: CKG Umum, CKG Sekolah, Sarana Puskesmas, Tatalaksana, Notifikasi Whatsapp, dan Cetak QR Screening.

Identitas Pengguna: Menampilkan nama fasilitas/nakes (Rizki Wahyudi Puskesmas Sedau) dan tombol Keluar.

Modul Utama Pencarian & Pendaftaran:

Tombol utama: Daftar Baru (untuk memulai entri pasien baru).

Kotak pencarian (input#searchNik / kolom tabel) untuk melacak nomor tiket dan status kunjungan.

3. Alur Pendaftaran (Workflow) Step-by-Step
Langkah Awal: Inisialisasi & Cek NIK
Pengguna berada di halaman utama pendaftaran dan mengklik tombol Daftar Baru.

Sistem membuka form input awal di mana pengguna memasukkan NIK (maksimal 16 karakter) pada elemen input#nik.

Pengguna mengklik tombol Cek NIK.

Jika data ditemukan di server Dukcapil: Sistem langsung menampilkan status "Data peserta valid" dan tombol Lanjutkan.

Jika data kosong/undefined: Sistem memicu form manual Step 1 di mana data identitas dasar harus diisi.

Langkah 1: Pengisian Data Identitas Dasar (Step 1)
Input Text (input#Nama Lengkap & input#No Whatsapp): Digunakan untuk mengetikkan nama lengkap sesuai KTP serta nomor WhatsApp aktif (dengan awalan otomatis +62).

Pilihan Tanggal Lahir (.mx-datepicker): Membuka modul kalender untuk memilih tanggal, bulan, dan tahun lahir.

Dropdown Jenis Kelamin: Menggunakan komponen kustom berbasis Vue. Membuka popup modal untuk memilih opsi teks (misalnya: Laki-laki / Perempuan).

Modul Kalender Jadwal Pemeriksaan (data-v-cdc79f1d):

Menampilkan grid kalender bulanan (contoh: Sep 2026).

Tombol tanggal menampilkan angka hari (1–31) disertai indikator kuota atau status (misalnya angka 900 atau titik hijau penanda tanggal aktif).

Setelah lengkap, pengguna mengklik tombol Selanjutnya.

Langkah 2: Pengisian Data Pendukung (Step 2 - Formulir Pendaftaran)
Setelah melewati validasi awal, stepper berpindah ke Step 2 ("Isi data pendukung"). Elemen yang terlibat meliputi:

Dropdown Bertingkat Kustom (Status Pernikahan, Disabilitas, Pekerjaan):

Fungsi: Karena bukan elemen <select> HTML biasa, saat diklik akan memunculkan modal overlay (.modal-content dengan z-9000).

Alur Interaksi: Modal menyediakan kolom pencarian teks (input placeholder="Cari pekerjaan"). Pengguna mengetik atau memilih dari daftar tombol pilihan (seperti Belum/Tidak Bekerja, Petani / Pekebun, Pegawai Swasta, dll) yang otomatis memfilter opsi di bawahnya.

Checkbox / Pilihan Khusus (Misalnya: "Tidak punya NIK"):

Fungsi: Mengubah status nilai boolean pada parameter noNik jika pasien tidak membawa atau memiliki NIK fisik.

Textarea Detail Alamat Domisili (textarea#detail-domisili):

Fungsi: Area teks multi-baris (rows="3", maksimal 60 karakter) untuk mencatat detail alamat spesifik (Contoh: Jl. Kenanga 14 no 92).

Langkah Akhir: Konfirmasi & Eksekusi Tiket
Setelah seluruh formulir Step 2 terisi lengkap, tombol Daftarkan yang sebelumnya berstatus bg-disabled (warna abu-abu, cursor-not-allowed) akan berubah menjadi aktif.

Klik pada tombol Daftarkan akan mengirimkan payload data ke server Kemenkes.

Pengguna diarahkan ke menu Pelayanan / Daftar Tiket untuk melakukan pencarian NIK, memvalidasi data pada baris tabel (tr), lalu mendapatkan Nomor Tiket resmi untuk proses skrining kesehatan lanjutan.
